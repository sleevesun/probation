# 【PRD】试用期管理及转正审批系统

## 一、需求背景

### 1.1 用户是谁

- 员工：处于试用期，需要设定试用期目标、查看过程反馈、填写试用期评价并查看最终结果。
- 直属上级：负责确认/退回员工试用期目标、记录阶段性反馈、完成正式试用期评价和试用期评价结果。
- HRBP：负责跟进试用期过程、在关键时间点开启评价，并在上级评价通过后发起转正审批。
- 审批人：在转正审批中查看试用期材料并完成审批。
- HR 管理者 / 业务负责人：需要通过系统留痕和流程推进，降低试用期管理风险。

### 1.2 用户问题是什么

- 员工入职后缺少统一的试用期目标沉淀，后续自评和上级评价缺少明确依据。
- 试用期过程中的问题反馈、沟通结论和整改要求主要在线下发生，系统内缺少阶段性记录。
- 上级和 HRBP 在 4.5 个月、5.5 个月等关键节点需要人工跟进，流程容易延迟。
- 转正审批材料分散，审批人无法在一个审批单中完整查看目标、自评、上级评价和审批记录。

### 1.3 目标是什么

- 建立员工试用期目标制定、确认、调整和锁定机制，使正式评估有目标依据。
- 在正式转正评估发起前，支持直属上级随时填写阶段性反馈，并允许员工侧查看。
- 在 4.5 个月节点推动 HRBP 开启正式评估，员工逐目标自评，直属上级完成评价并给出试用期评价结果。
- HRBP 基于目标、自评和上级评价发起转正审批，审批人可查看完整材料并审批。

## 二、产品概述

### 2.1 业务流程图

![试用期转正业务流程图](/图示/试用期转正业务流程图.svg)

```text
员工制定目标
-> 直属上级确认目标 / 退回修改
-> 直属上级可填写阶段性反馈
-> HRBP 在 4.5 个月节点开启试用期评价
-> 员工逐目标自评 + 总体评价
-> 直属上级评价 + 试用期评价结果
-> HRBP 预览并发起转正审批流程
-> 审批人审批
-> 审批通过后进入待发布
-> 员工身份由试用员工变更为正式员工
-> 系统自动发布转正结果并通知员工
-> 员工查看结果
```

### 2.3 状态流转

![试用期转正状态流转图](/图示/试用期转正状态流转图.svg)

| 状态码 | 状态名称 | 当前处理人 | 进入条件 | 可操作动作 | 下一状态 |
| --- | --- | --- | --- | --- | --- |
| 01 | 待设定目标 | 员工 | 员工入职后具备权限并生成记录，或目标被退回；入职 1 周后推送目标设定待办 | 保存草稿、提交目标 | 02 |
| 02 | 目标待确认 | 直属上级 | 员工提交目标 | 确认目标、退回修改 | 03 / 01 |
| 03 | 目标已确认 | 无固定处理人 | 上级确认目标 | 上级可在评估开启前退回调整；直属上级可填写阶段性反馈；入职满 4.5 个月后 HRBP 可直接开启评价或终止转正 | 01 / 05 / 99 |
| 05 | 待员工自评 | 员工 | HRBP 开启评价 | 提交逐目标自评和总体评价 | 06 |
| 06 | 待上级评价 | 直属上级 | 员工提交自评 | 提交评价；HRBP 可终止转正 | 07 / 99 |
| 07 | 上级已评价 | HRBP | 上级提交通过类试用期评价 | 发起转正、终止转正 | 08 / 99 |
| 08 | 审批中 | 审批人 | HRBP 发起转正审批流程 | 通过、驳回 | 09 / 07 |
| 09 | 待发布 | 系统 | 审批通过，但员工类型尚未由试用员工变更为正式员工 | 监听员工身份变更并自动发布结果 | 10 |
| 10 | 结果已发布 | 无 | 员工身份由试用员工变更为正式员工，系统自动发布结果并通知员工 | 员工查看结果和试用期评价结果 | 结束 |
| 99 | 不通过 | 无 | HRBP 手动终止流程，或上级评价不通过 | 查看记录，按需跳转相关人事流程 | 结束 |
| 11 | 未转正离职 | 无 | 员工在完成试用期转正流程前已离职 | 查看记录 | 结束 |

状态规则：

**评价构成规则：**

- 正式评价由员工自评和直属上级评价构成；HRBP 负责开启评价、流程跟进和发起转正审批流程，不填写独立的正式评价。
- 员工提交自评后进入直属上级评价；上级提交通过类评价后由 HRBP 发起转正审批。
- 上级试用期评价选择”不通过”时，记录直接进入”不通过”结果并归入”已结束”，不进入 HRBP 发起转正审批环节；系统通知 HRBP，不向员工发送结果通知。

**阶段性反馈规则：**

- 阶段性反馈不是必经节点，不改变主流程状态，也不进入转正审批流程。
- 正式评估发起前，直属上级可新增阶段性反馈，员工和 HRBP 均以只读方式查看。
- 正式评估发起后，阶段性反馈入口转为只读，仅可查看历史记录，不再新增阶段性反馈。

**终止转正规则：**

- HRBP 在正式评估开启前的所有状态均可执行”终止转正”，包括待设定目标、目标待确认、目标已确认。
- HRBP 在正式评估开启后、发起转正审批前均可执行”终止转正”，包括”待员工自评””待上级评价””上级已评价”三个阶段；执行后记录评价结果为”不通过”，归入”已结束”。
- HRBP 发起转正审批流程后，”终止转正”操作不可用。
- HRBP 手动终止流程时，需填写终止说明；HRBP、直属上级等有权限角色可在详情和已结束列表中查看”不通过”结果，员工侧不发布该结果。
- HRBP 手动终止流程后，系统自动生成上级评价内容，格式为：`HRBP [姓名] 手动终止流程（YYYY-MM-DD） 终止原因：[终止说明]`。

**目标锁定规则：**

- HRBP 开启正式评估后，目标进入只读锁定状态。

**审批相关规则：**

- 审批退回默认回到”上级已评价”，由 HRBP 判断是否重新发起或退回前序评价；如审批系统已有规则，以审批系统配置为准。
- 审批通过后记录进入”待发布”。如果审批通过时已到或超过 6 个月试用期节点，员工身份立即变更为正式员工，系统立即自动发布转正结果并通知员工；如果审批提前通过，则等待员工身份由试用员工变更为正式员工后自动发布并通知员工。

**结果发布规则：**

- 结果自动发布前，员工不可查看直属上级评价结果和审批记录；结果自动发布后，员工可以查看试用期评价结果，但不可查看审批记录。

**离职处理规则：**

- 员工在完成试用期转正流程前离职时，系统自动作废所有未完成表单，记录进入”已结束”，状态显示”未转正离职”。

## 三、功能性需求

### 3.1 [1][2][3] 员工端 - 我的试用期

#### 1. 基础逻辑

- 员工进入系统后查看本人试用期相关信息。
- 员工端展示本人试用期信息、可处理事项和面向员工的流程进展；结果发布后展示试用期评价结果。
- 员工当前状态模块命名为“当前进展”，用于承载可处理待办和不可处理的进展信息。
- Demo 中的员工切换组件放在侧边栏区域，不放在页面主体内容区。
- Demo 员工切换组件展示在左侧菜单栏。

#### 2. 页面详细说明

页面构成：

| 区域 | 说明 |
| --- | --- |
| 员工切换 | Demo 辅助组件，放在侧边栏，用于切换演示员工 |
| 页面标题 | 展示“我的试用期”和入职天数 |
| 当前状态 | 展示在页面标题下方 |
| 员工信息 | 展示员工基础信息，位于当前进展上方 |
| 当前进展 | 展示员工当前所处阶段、当前状态和下一步动作 |
| 试用期目标 | 展示员工已填写目标；未填写时展示“试用期目标”按钮，点击后打开目标弹窗 |
| 反馈记录 | 展示直属上级提交的阶段性反馈；最终通过转正后，同时展示直属上级的试用期评价 |
| 试用期自评 | 正式评估开启后展示“试用期自评”按钮，点击后打开自评弹窗；已提交后展示自评内容 |
| 结果信息 | 结果自动发布后展示最终通过结果和试用期评价结果；员工结果通知仅在通过类结果发布时触发 |

展示逻辑：

**页面布局：**

- 员工首页入职天数展示为”已入职 XXX 天”。
- 当前状态展示在”我的试用期”标题下方，不放在页面右上角。
- 员工信息和当前进展采用上下结构，员工信息在上，当前进展在下。
- 员工端侧边栏展示”我的试用期”入口，目标和自评操作通过页面内按钮进入。

**状态展示：**

- 员工视角步骤展示为：`提交目标 -> 上级确认 -> 试用期评价 -> 试用期评估中 -> 完成`。
- 待设定目标状态下，当前进展说明文案为：`请与上级沟通后完成试用期目标设定，并提交上级确认。`
- 上级确认目标后，到员工需要自评前，员工阶段展示为”上级确认”，状态展示为”【进行中】目标已确认”。
- 目标确认后、评价开启前，员工端展示”目标已确认”状态。
- 员工提交自评后，员工端统一展示为”试用期评估中”，不拆分展示”待上级评价””上级已评价””审批中”等后台状态。

**数据展示：**

- 员工侧记录区域命名为”反馈记录”。
- 最终通过转正后，”反馈记录”区域除展示阶段性反馈外，还需展示直属上级最终试用期评价。
- 已确认目标及后续阶段的演示员工，需要预置直属上级阶段性反馈数据，避免阶段性反馈记录长期为空。

#### 3. 功能交互

- 当前存在待办时，在“我的试用期”页展示对应主按钮，如“试用期目标”“试用期自评”。
- 当前进展卡片中的“去填写”和快捷操作区的“试用期目标”按钮打开同一个目标弹窗。
- 目标被退回时，当前进展卡片中的“去修改”和快捷操作区的“试用期目标”按钮打开同一个目标弹窗。
- 试用期自评待办状态下，当前进展卡片中的“去填写”和快捷操作区的“试用期自评”按钮打开同一个自评弹窗。
- 点击“试用期目标”按钮，在当前页打开目标弹窗，不跳转独立目标设定页面。
- 点击“试用期自评”按钮，在当前页打开自评弹窗，不跳转独立试用期评价页面。
- 员工端目标弹窗和自评弹窗尺寸保持一致，桌面端约占当前浏览器可视区域的 3/5；弹窗内容超出时在弹窗内部滚动。
- 当前无员工可操作事项时，仅展示当前进展。
- 反馈记录为只读内容。

### 3.2 [5][6] 员工端 - 试用期目标

#### 1. 基础逻辑

- 员工入职后进入“待设定目标”状态。
- 员工最多填写 5 条试用期目标。
- 目标提交后进入直属上级确认。
- HRBP 开启正式评估后，目标锁定为只读。
- 员工在“我的试用期”页点击“试用期目标”按钮，通过弹窗填写、提交或查看目标。

#### 2. 字段说明

| 字段 | 字段说明 | 是否必填 | 规则 |
| --- | --- | --- | --- |
| 序号 | 目标行序号 | 否 | 系统按目标行自动生成，从 1 开始展示 |
| 目标内容 | 试用期内需要完成的事项 | 是 | 开放文本；页面列名需展示必填标识 |
| 预期结果 | 后续评价时参考的结果或标准 | 是 | 开放文本；页面列名需展示必填标识 |
| 权重 | 目标重要性辅助信息 | 否 | 可为空；如填写权重，各目标权重合计需为 100% |
| 备注 | 资源、协作、阶段说明等补充信息 | 否 | 开放文本 |

#### 3. 功能交互

**基本操作：**

- 员工可新增、编辑、删除目标。
- 员工可保存草稿。
- 员工点击”提交”后，系统校验必填字段和权重规则。
- 提交成功后进入”目标待确认”，直属上级生成目标确认待办。
- 目标被退回后，员工可查看退回意见并重新编辑提交。

**列表展示：**

- 员工目标列表第一列展示”序号”。
- 员工自评和各类详情/预览中的目标字段展示”预期结果”。
- Demo 员工切换列表中移除”赵雪梅”演示员工。

**弹窗提示：**

- 目标弹窗顶部只展示一条单行紧凑提示，不同时展示多条 Alert。
- 待填写或可编辑状态下，提示文案展示”请填写试用期内的目标”或等价文案。
- 目标已确认、流程已进入后续阶段或其他只读状态下，提示文案与锁定说明合并为一行，例如”目标已锁定，您的试用期目标已被确认或流程已往后流转，目前只能查阅不可修改。”
- 目标弹窗中的”目标已锁定”提示使用单行紧凑样式。

**退回状态：**

- 目标被退回时，退回提示与其他当前进展状态使用同一组件样式。
- 目标被退回时，退回意见在当前进展说明中展示，”去修改”按钮放在组件右侧，与”去填写”按钮位置一致。

**按钮交互：**

- “去填写””去修改”和”试用期目标”按钮打开同一个目标弹窗。

**弹窗尺寸：**

- 目标弹窗尺寸桌面端约为浏览器可视区域的 3/5；移动端按屏幕宽度自适应，不应超出屏幕。

#### 4. 校验规则

| 场景 | 处理规则 |
| --- | --- |
| 所有目标权重均为空 | 允许提交，不触发权重合计校验 |
| 部分目标填写权重 | 不允许提交，提示补齐全部目标权重并保证合计 100% |
| 全部目标填写权重且合计为 100% | 允许提交 |
| 全部目标填写权重但合计不为 100% | 不允许提交，提示调整权重 |

提示文案：

- 权重说明：`可选；如填写权重，各目标权重合计需为 100%。`
- 部分填写权重：`如需使用权重，请为全部目标填写权重，并保证合计为 100%。`
- 合计不为 100%：`已填写目标权重时，权重合计需为 100%。`

### 3.3 [4] 员工端 - 反馈记录

#### 1. 基础逻辑

- 员工侧允许查看直属上级提交的阶段性反馈。

### 3.10 [14] HRBP 端 - 开启评价 / 终止转正

#### 1. 基础逻辑

- 入职满 4.5 个月且目标已确认时，HRBP 在“目标已确认”状态下收到开启评价待办，并可直接操作“开启评价”。
- HRBP 可开启正式评估，也可在发起转正审批前选择“终止转正”。
- “终止转正”按钮适用于所有正式评估未开启前的状态，包括待设定目标、目标待确认、目标已确认。
- 员工处于“待员工自评”“待上级评价”“上级已评价”时，HRBP 可执行“终止转正”。
- HRBP 手动终止流程后，记录评价结果为“不通过”，进入“已结束”Tab。
- HRBP、直属上级等有权限角色查看详情时，试用期评价结果展示为“不通过”；员工侧不发布该结果。
- HRBP 手动终止流程时必须填写终止说明，该说明自动带入上级试用期评价内容。

#### 2. 功能交互

| 操作 | 触发条件 | 交互规则 | 结果 |
| --- | --- | --- | --- |
| 开启评价 | 入职满 4.5 个月且目标已确认 | 点击后弹出轻量确认弹窗 | 员工收到自评待办，目标锁定 |
| 终止转正 | 正式评估开启前的任一状态，或待员工自评、待上级评价、上级已评价状态；发起转正审批后不可终止 | 点击后弹出二次确认，要求填写终止说明 | 评价结果记录为“不通过”，进入“已结束” |

确认弹窗规则：

**开启评价弹窗：**

- 点击”开启评价”不需要展示员工详情表单，只弹出轻量确认弹窗。
- “开启评价”确认弹窗只提示 HR：`确认后将通知该员工开始填写试用期自评。`

**终止转正弹窗：**

- “终止转正”确认弹窗需要包含终止说明输入框，终止说明必填。
- “终止转正”确认弹窗文案统一为：`该员工将被记录为”不通过”，并进入”已结束”，不再继续转正流程。`
- HRBP 提交终止说明后，系统自动写入上级试用期评价内容，格式为：`HRBP [姓名] 手动终止流程（YYYY-MM-DD） 终止原因：[终止说明]`。

### 3.12 系统自动发布结果

#### 1. 基础逻辑

- 审批通过后记录进入“待发布”；当员工身份由“试用员工”变更为“正式员工”时，系统自动发布转正结果。
- 如果审批通过时已到或超过 6 个月试用期节点，员工身份立即变更为正式员工，系统立即自动发布转正结果并通知员工。
- 结果自动发布前，员工不可查看直属上级评价结果和审批记录。
- 结果自动发布后，员工可以查看试用期评价结果，但不可查看审批记录。

#### 2. 功能交互

- 员工身份变更为正式员工时，系统自动发布结果并通知员工；员工结果通知仅在通过类结果发布时发送。
- 员工仅在结果自动发布后查看试用期评价结果。
- 员工在任一状态下均不可查看审批记录。

### 3.13 [17][18] 审批端 - 转正审批

### 3.14 [19] 通知与待办

![试用期转正通知与待办流转图](/图示/试用期转正通知与待办流转图.svg)

#### 1. 基础逻辑

- 系统需区分“待办”和“待审批”两类事项：待办用于目标设定、目标确认、自评、上级评价、开启评价、发起审批等业务动作；待审批用于转正审批人处理审批单。
- 待办通过邮件 + WOA 发送提醒，WOA 消息需特别注明“仅限 PC 端打开”，并在 OA 消息中心显示待办。
- 待审批通过邮件 + OTP 通知，在 OTP 待处理和 OA 消息中心均提示。
- 审批支持移动端处理；目标、自评、评价等业务待办在 PC 端处理。
- 通知 Demo 展示“待办与通知预览”。
- 通知 Demo 右侧预览模拟 Outlook 邮件查看容器。
- 通知 Demo 覆盖目标设定、评价、转正审批和结果自动发布相关通知。

#### 2. 通知场景

**目标设定阶段：**

| 场景 | 触发条件 | 接收人 | 形式 | 系统动作 |
| --- | --- | --- | --- | --- |
| 目标设定待办 | 员工入职后即具备权限，入职满 1 周后推送提醒 | 员工 | 待办 + 通知 | 填写并提交目标 |
| 目标退回待办 | 上级退回目标 | 员工 | 待办 + 通知 | 修改并重新提交 |
| 目标确认待办 | 员工提交目标 | 直属上级 | 实时待办 + 通知 | 确认目标或退回修改 |
| 目标提交通知 | 员工提交试用期目标 | 直属上级、HRBP | 实时通知 | 直属上级确认目标；HRBP 跟进后续确认进度 |

**目标跟进提醒：**

| 场景 | 触发条件 | 接收人 | 形式 | 系统动作 |
| --- | --- | --- | --- | --- |
| 3 个月目标已提交未确认提醒 | 入职满 3 个月，员工已提交目标但上级尚未确认 | HRBP | 通知 | 跟进直属上级尽快确认目标 |
| 3 个月员工未提交目标提醒 | 入职满 3 个月，员工尚未提交试用期目标 | 直属上级、HRBP | 通知 | 直属上级督促员工提交；HRBP 跟进员工和上级 |
| 4.5 个月目标未确认提醒 | 入职满 4.5 个月且目标仍未确认 | 直属上级、HRBP | 通知 | 保持目标当前状态，不自动确认；直属上级尽快完成目标确认，HRBP 推动确认进度 |

**评价阶段：**

| 场景 | 触发条件 | 接收人 | 形式 | 系统动作 |
| --- | --- | --- | --- | --- |
| 开启评价待办 | 入职满 4.5 个月且目标已确认 | HRBP | 待办 + 通知 | 开启评价或终止转正 |
| 员工自评待办 | HRBP 开启评价 | 员工 | 待办 + 通知 | 提交试用期评价 |
| 自评进行通知 | HRBP 开启评价 | 直属上级 | 通知 | 知晓员工正在自评，等待后续评价待办 |
| 上级评价待办 | 员工提交自评 | 直属上级 | 待办 + 通知 | 给出试用期评价 |
| 评估跟进通知 | 员工提交自评 | HRBP | 通知 | 跟进上级评价进度 |
| 上级评价不通过通知 | 上级提交”不通过”试用期评价 | HRBP | 通知 | 知晓该员工评价结果为”不通过”，并跟进后续人事处理 |
| 上级评价通过通知 | 上级提交通过类试用期评价 | HRBP | 待办 + 通知 | 发起转正 |

**评价推进提醒：**

| 场景 | 触发条件 | 接收人 | 形式 | 系统动作 |
| --- | --- | --- | --- | --- |
| 5.5 个月评估推进提醒 | 入职满 5.5 个月仍未发起转正审批流程 | 直属上级、HRBP | 通知/待办提醒 | 如自评或上级评价尚未完成，推动前序环节完成；如评价已完成，推动 HRBP 发起转正审批流程 |
| 5.5 个月未发起审批升级通知 | 入职满 5.5 个月仍未发起转正审批流程 | HRD、HRBP head | 通知 | 知晓转正审批发起延迟，并推动 HRBP 完成后续处理 |

**转正审批阶段：**

| 场景 | 触发条件 | 接收人 | 形式 | 系统动作 |
| --- | --- | --- | --- | --- |
| 发起转正待办 | 上级提交通过类试用期评价 | HRBP | 待办 + 通知 | 发起转正 |
| 审批待办 | HRBP 发起转正审批流程 | 审批人 | 待审批 | 查看审批单并审批 |
| 审批通过通知 | 转正审批通过 | HRBP、直属上级 | 通知 | 知晓审批已通过；如未到身份变更时间，记录进入待发布 |
| 审批驳回通知 | 转正审批被驳回 | HRBP、直属上级 | 通知 | 知晓审批被驳回；HRBP 判断是否重新发起或回退处理 |

**结果发布阶段：**

| 场景 | 触发条件 | 接收人 | 形式 | 系统动作 |
| --- | --- | --- | --- | --- |
| 结果自动发布通知 | 员工身份由试用员工变更为正式员工，系统自动发布结果；若审批通过时已到或超过 6 个月则立即触发 | 员工 | 通知 | 员工知晓试用期转正审批已通过，并查看结果和上级评价 |

#### 3. 渠道与展示规则

- 员工端在目标已确认后、评估开启前展示“目标已确认”状态。
- WOA 待办消息需注明“仅限 PC 端打开”。

## 四、其他需求

### 4.1 权限需求

![试用期转正角色权限关系图](/图示/probation_role_permission_fixed.svg)

| 角色 | 可见范围 | 可操作内容 |
| --- | --- | --- |
| 员工 | 本人试用期记录 | 填写目标、自评；查看阶段性反馈和结果 |
| 直属上级 | 直接下属试用期记录 | 确认/退回目标、填写阶段性反馈、填写上级评价 |
| HRBP | 权限范围内员工试用期记录 | 开启评价、发起转正、流程跟进 |
| 审批人 | 待本人审批的转正审批单 | 查看审批材料、通过、驳回 |

权限规则：

- 正式评价由员工自评和直属上级评价构成；HRBP 负责开启评价、流程跟进和发起转正审批流程。
- 结果自动发布前，员工不可查看直属上级评价结果和审批记录。
- 结果自动发布后，员工可以查看试用期评价结果，但不可查看审批记录。
- 审批记录仅对 HRBP、直属上级和审批相关角色展示。
- 员工以只读方式查看阶段性反馈。
- HRBP 以只读方式查看直属上级提交的阶段性反馈。

| 场景 | 处理规则 |
| --- | --- |
| 员工未提交目标 | 入职满 1 周后目标设定待办持续存在；入职满 3 个月仍处于目标设定/确认阶段时触发目标跟进提醒 |
| 目标被退回 | 员工重新进入目标编辑状态；退回意见可见 |
| 目标权重全部为空 | 允许提交，不触发权重合计校验 |
| 目标权重部分填写 | 不允许提交，需补齐全部目标权重并保证合计 100% |
| 目标权重合计不为 100% | 不允许提交，提示调整权重 |
| 上级已确认但评估未开启 | 上级仍可退回目标，员工重新调整 |
| 到 4.5 个月目标仍未确认 | 保持目标当前状态，不自动确认；系统通知直属上级和 HRBP 推动目标确认 |

### 5.2 阶段性反馈异常

| 场景 | 处理规则 |
| --- | --- |
| 阶段性反馈无目标 | 弹窗目标区域展示”暂未完成试用期目标制定” |
| 反馈记录为空 | 员工侧展示”暂无反馈记录” |
| HRBP 查看阶段性反馈 | HRBP 以只读方式查看直属上级提交的阶段性反馈 |
| 正式评估已开启 | 阶段性反馈入口转为只读，仅展示历史记录 |

### 5.3 评价相关异常

| 场景 | 处理规则 |
| --- | --- |
| 员工未完成自评 | 自评待办持续存在；5.5 个月可触发推进提醒 |
| 上级未完成评价 | 上级评价待办持续存在；5.5 个月可触发推进提醒 |
| 上级评价不通过 | 记录评价结果为”不通过”，进入”已结束”，不进入 HRBP 发起转正审批环节；通知 HRBP 跟进后续人事处理，不向员工发送结果通知 |
| HRBP 终止转正 | 仅可在发起转正审批流程前操作；必须填写终止说明；单据评价结果记录为”不通过”，进入”已结束”，员工侧不发布该结果 |

### 5.4 审批相关异常

| 场景 | 处理规则 |
| --- | --- |
| 入职满 5.5 个月仍未发起审批 | 触发推进提醒；通知直属上级、HRBP、HRD、HRBP head；如前序自评或上级评价未完成，则同步推动完成 |
| 审批退回/拒绝 | 默认回到 HRBP”上级已评价”状态；如审批系统已有回退规则，以审批系统配置为准 |
| 无 HRD 或审批节点缺失 | 按现有审批配置处理，可能由 HRBP 自审批或节点跳过 |
| 审批通过后身份未变更 | 记录进入”待发布”，系统等待员工身份从试用员工变更为正式员工 |

### 5.5 离职与结果发布异常

| 场景 | 处理规则 |
| --- | --- |
| 员工未完成转正流程前离职 | 系统自动作废所有未完成表单，将人员放入”已结束”，状态显示”未转正离职” |
| 员工身份变更为正式员工 | 系统自动发布转正结果并通知员工，员工默认可查看试用期评价结果 |

## 七、验收标准

### 7.1 流程验收

#### 1. 目标管理流程

- 员工可新增 1-5 条目标并提交。
- 员工目标列表第一列展示系统生成的”序号”。
- 员工目标中的”目标内容”和”预期结果”为必填，并在页面列名中展示必填标识。
- 员工可不填写目标权重并提交。
- 员工填写任一目标权重时，需要全部目标填写权重且合计为 100% 后才能提交。
- 上级可确认目标，也可通过二次确认弹窗填写退回意见后退回目标。
- 退回意见在退回二次确认弹窗中填写。
- 上级在 HRBP 开启评价前可退回已确认目标。
- 上级目标确认弹窗展示目标序号、目标内容、预期结果、权重和备注。

#### 2. 阶段性反馈流程

- 直属上级在正式转正评估发起前可填写阶段性反馈，HRBP 可只读查看。
- 阶段性反馈不改变主流程状态，不阻断后续转正评估发起，也不进入转正审批流程。
- 员工以只读方式查看反馈记录。
- 正式转正评估发起后，阶段性反馈入口转为只读，仅可查看历史记录。

#### 3. 评价流程

- 正式评价由员工自评和直属上级评价构成；HRBP 负责开启评价、流程跟进和发起转正审批流程，不填写独立的正式评价。
- 员工提交自评后，上级可填写评价意见和试用期评价结果。
- 试用期评价结果选项展示为”通过（超出预期）””通过（符合预期）””不通过”。
- 上级评价意见为必填项，无论选择通过或不通过均需填写。
- 上级提交”不通过”试用期评价后，记录评价结果为”不通过”，进入”已结束”，不进入 HRBP 发起转正审批环节；系统通知 HRBP，不向员工发送结果通知。

#### 4. 终止转正流程

- HRBP 点击”开启评价”前需要轻量确认；确认文案为”确认后将通知该员工开始填写试用期自评。”
- HRBP 执行”终止转正”时，二次确认弹窗必须填写终止说明。
- HRBP 执行”终止转正”后，该员工的试用期记录评价结果为”不通过”，进入”已结束”。
- HRBP 发起转正审批流程后，不再展示或允许执行”终止转正”。
- HRBP 填写的终止说明自动带入上级试用期评价内容，格式为”HRBP [姓名] 手动终止流程（YYYY-MM-DD） 终止原因：[终止说明]”。

#### 5. 转正审批流程

- 上级提交通过类试用期评价后，HRBP 可通过”发起转正”查看审批单预览，并点击”发起转正审批流程”提交。
- 审批详情展示目标、员工自评、上级评价、阶段性反馈和审批记录。

#### 6. 结果发布流程

- 审批通过后进入”待发布”；员工身份变更为正式员工后，系统自动发布结果。
- 审批通过时已到或超过 6 个月试用期节点，员工身份立即变更为正式员工，系统立即自动发布结果并通知员工。
- 结果自动发布前，员工不可查看直属上级评价结果和审批记录；结果自动发布后，员工可查看试用期评价结果，但仍不可查看审批记录。

### 7.2 页面验收

#### 1. 员工端页面

**基础布局：**

- 员工首页当前状态模块命名为”当前进展”。
- 员工首页入职天数展示为”已入职 XXX 天”。
- 员工切换组件放在侧边栏，不占用员工首页主体内容区。
- 员工当前状态展示在页面标题下方。
- 员工信息和当前进展为上下结构，员工信息在上；员工信息区域桌面端每行展示 3 个字段。

**状态展示：**

- 员工端在目标已确认到 HRBP 开启评价前，阶段保持”上级确认”，状态展示”【进行中】目标已确认”。

- 员工提交自评后，员工端统一展示”试用期评估中”。
- 员工端非自评阶段的提示条使用一行紧凑样式展示。

**按钮与弹窗：**

- 员工端在”我的试用期”页展示”试用期目标”和”试用期自评”按钮。

**详情展示：**

### 7.3 通知验收

#### 1. 目标设定阶段通知

- 员工入职后具备目标设定权限，入职满 1 周后生成目标设定待办和提醒。
- 员工提交目标后，上级生成目标确认待办。
- 上级退回目标后，员工生成重新提交待办。
- 系统在入职满 3 个月时生成目标跟进提醒。
- 入职满 4.5 个月且目标仍未确认时，系统不自动确认目标，并通知直属上级和 HRBP 推动确认。
- HRBP 收到 4.5 个月开启评价提醒时，列表状态展示”目标已确认”。

#### 2. 评价阶段通知

- HRBP 开启评价后，员工生成自评待办。
- 员工提交自评后，上级生成评价待办。
- 上级评价待办通知中的期望动作统一为”请给出试用期评价”。
- 上级提交”不通过”试用期评价后，系统通知 HRBP。
- 上级提交通过类试用期评价后，系统通知 HRBP 可以发起转正。
- 系统在入职满 4.5 个月时生成开启试用期评价提醒，在入职满 5.5 个月时生成评估推进提醒。

#### 3. 审批阶段通知

- 上级提交通过类试用期评价后，HRBP 生成发起转正待办。
- 审批人收到转正审批待审批通知。
- 入职满 5.5 个月仍未发起转正审批流程时，系统通知直属上级、HRBP、HRD 和 HRBP head。
- 转正审批通过或被驳回后，系统通知 HRBP 和直属上级。

#### 4. 结果发布阶段通知

- 转正审批通过后进入”待发布”。
- 员工身份由试用员工变更为正式员工后，系统自动发布结果并通知员工试用期转正审批已通过。

#### 5. 通知渠道规则

- 待办通过邮件和 WOA 触达，WOA 消息注明”仅限 PC 端打开”，并在 OA 消息中心显示待办。
- 待审批通过邮件和 OTP 触达，并在 OTP 待处理和 OA 消息中心均提示。
- 审批支持移动端处理，其他业务待办在 PC 端处理。
