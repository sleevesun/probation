## 使用建议

- PRD 中优先以相对路径引用这些图，保证仓库同步后可直接预览。
- Demo 或 PPT 需要封面图时，可复用这些 `SVG` 或再导出为 `PNG`。
- 后续若继续用 Excalidraw 迭代，优先编辑同名 `.excalidraw` 源文件，再导出覆盖同名 `SVG`，保持文件名稳定。
